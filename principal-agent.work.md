# principal-agent

The user's words: principal-agent theory is "the entire problem", the reason they still need to find a way of staying inside the loop. It is not for `philosophy/mandate.md`; it is to be used somewhere else, not yet chosen.

## What was told to the user, the material to place

Principal-agent theory (Jensen & Meckling, 1976; Holmström, 1979): a principal delegates to an agent that knows more than it does. Hidden information before the work, the agent's ability cannot be told; hidden action during it, what the agent did cannot be seen.

The cost of delegating, the agency costs, as read onto the harness:

- monitoring, the principal checks: the user rereading the work, context spent
- bonding, the agent proves itself: the report, the runs kaizen has made reliable
- residual loss, what still slips through: what was swept under the rug (φmandate)

The multitask result (Holmström & Milgrom, 1991): measure one part of a job and the agent neglects the rest; "make the tests pass" yields passing tests and a worse model.

The incentive half of the theory does not apply, a model has no interest to align; the information half does.
