# Mandate

**Thesis.** In a session, an agent delegates work to a sub-agent, a workflow or a script through a mandate that is clearly bounded (Auftragstaktik, the mission order).

The same holds one rung up, the user over the session (φabstraction-ladder).

## The mandate

A mandate lists what is in. The exception cannot be listed, the unknown unknowns least of all; listing it is **enumerating badness** (Ranum). So the business as usual is declared (φmetis-kairos), and the exception is everything else.

A mandate states what the one above expects of the task, not what the one below is allowed. A brief that states none expects the narrowest: what was asked, precisely.

Every mission order is a hypothesis of realizability: what does not fit falsifies it, and the expectation is what changes: the exception climbs, the andon is pulled. Done or falsified, both are results. Four faults keep it below:

- **overreach**: scope creep, doing the rest too
- **compensation**: a local fix (φsystems-of-compensations), the quick translation a spork grows from
- **specification gaming**
- **sweeping it under the rug**

## Where it ends

Taylor's **exception principle**: a standard is set, and only the deviation climbs. Here the standard is an expectation, not a measure, and nobody above watches for the deviation: the one acting feels it. A task inside its mandate is straightforward.

The test at each move: could this surprise the echelon above? Measured against the brief: what the brief already settled is never a surprise. What surprises when the brief names nothing: φmetis-kairos.

## How wide

A mandate reaches as far as the brick has proven reliable (φharness-direction). Reliable means the result is taken unchecked. No operator stands over the run; the echelon above reads the report and does not redo the work.

## What climbs

A mismatch is never forced through. Two questions follow, kept apart:

- **Is it a surprise?** The test above, the same in every mode.
- **Decide alone, or climb?** Judged on the nature of the change, not its size: a premise or a foundation against a small consequence, the blast radius, whether it can be reviewed afterwards. The bar moves with access:

```
 the user accessible  ◀──────────────────────────▶  the user out of reach
 mecha suit                                          autopilot
 low bar: it climbs early                            high bar: decided within the intent,
                                                     named in the debrief
```

## Upstream

The mode is the user's choice, made before the brief, where two sides meet: what the work deserves of the user's attention, the scarce resource (Simon), and what the user has to give. The agent sees only its consequence: access.

```
 WHAT THE TASK ASKS                          WHAT THE USER HAS TO GIVE
 ──────────────────────────────              ──────────────────────────────
 theory, to steer later    (always)          present, engaged
 quality the machine       (for now)         multitasking
   does not reach yet                        away, asleep
 nothing

 the task asks, the user is there   ──▶  mecha suit, in the loop
 the task asks, the user is away    ──▶  autopilot, the attention paid later:
                                         the work reviewed whole
 the task asks nothing              ──▶  autopilot, wherever the user is
```

- **Theory.** Being in the loop is theory building (Naur), enacted cognition: what the user needs to keep steering in the long term. Modeling what sits at the core asks for it, and no skill removes that.
- **Quality.** A brick not yet proven is steered move by move. This is a harness gap, and closing it frees the work for autopilot (φharness-direction).
- **Nothing.** A proven workflow, tooling, a probe. A probe in code is an epistemic action (Kirsh & Maglio) standing on a rollback that is given, not designed in.

Neither side causes the other: the user adjusts whichever is free. Going to bed fixes what there is to give, and the work is picked to fit; a core model fixes what is asked, and the user shows up. Mission command assumes a commander out of reach; here the echelon above is often one message away. The image is **NASA mission control**: the crew flies the nominal alone, the off-nominal goes to the ground, and crew autonomy grows with the communication delay.

Each end has its fault:

- **The long screwdriver**, the field's own name: the echelon above reaches down into the nominal and steers each move.
- **Upward delegation** (Oncken & Wass, the monkey): the one below yields its turn with work left in its mandate: roger without wilco, or mother-may-I.
