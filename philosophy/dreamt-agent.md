# The dreamt agent

**Thesis.** An LLM is a simulator (Janus): it dreams a conversation between a human and an agent, the human's turns are supplied, the agent is a simulacrum (Baudrillard), and the harness is what makes it an actant.

## The dream

An LLM is a simulator (Janus), and the agent one of its simulacra. It is the library, not the librarian (Gopnik, φmodel-phenomenology), and a library holds more than one character: the LLM can dream any that its weights hold. What it dreams here is a conversation between a human and an agent. The human's turns are supplied to it, so that half it cannot fully dream. The agent's turns are purely the dream.

## A simulacrum that acts

The agent is a simulacrum (Baudrillard), of the last order.

The harness is everything around the LLM: the tooling that operationalizes the dream. It gives the simulacrum affordances (Gibson), and through them it becomes an actant (Latour): it acts.

## No instruction is obeyed

The engineer never directs an agent. No agent is there to obey an instruction: there is an LLM that imagines what an agent would do, given the context. An instruction is one more piece of that context.

So the engineer acts through level design only (φlevel-design): what the LLM reads and the constraints around it are what can be changed. The weights are given.

The level is what selects which character is dreamt: a name sets a posture, and a scene pulls harder than a rule (φattractors, φcollaborative-production).
