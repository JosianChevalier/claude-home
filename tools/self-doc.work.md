# self-doc

Each script carries a `--help`-shaped comment block under its shebang; `run doc <platform>` prints every tool's help, project tools first, `run doc <tool>` one tool's. Claude's SessionStart hook runs it. OpenCode's `instructions` can only load files, so `docs/opencode.md` is its output committed, regenerated by hand: `run doc opencode > tools/docs/opencode.md`.
