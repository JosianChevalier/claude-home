# Writing

## Doctrine

- A document is skimmed before it is read. Shape first, then prose.
- Each piece of information in the medium that carries it cheapest: simple prose, a list, a table, a figure.
- Breathability wherever a human might open the file: agents read anything, humans stop at a wall of text.

## Know-how

- One idea per paragraph, and paragraphs short. A long paragraph holds two ideas; split it.
- The medium follows the information:
  - parallel items → list
  - their examples → sub-list
  - a comparison across dimensions → table
  - a sequence or a loop → ascii figure
  - text from or for a file → code block
  - an argument, a definition → simple prose
- The claim comes before its argument.
- A section earns its heading when a reader would jump to it.
- A reader who has read only the headings and the first sentences has the map.
